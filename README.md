# 💻 Laptop Recommender System

[![React](https://img.shields.io/badge/React-18-blue)](https://reactjs.org/)
[![PHP](https://img.shields.io/badge/PHP-8-purple)](https://www.php.net/)
[![MySQL](https://img.shields.io/badge/MySQL-8-orange)](https://www.mysql.com/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

> An intelligent web application that helps users find the perfect laptop based on their specific needs using a weighted scoring algorithm.


## ✨ Features

### 🔍 Intelligent Recommendation Engine
- **20-Question Survey**: Comprehensive questions covering usage, budget, and preferences
- **Weighted Scoring Algorithm**: Matches users with the most suitable laptop
- **Real-time Results**: Instant recommendations without page reload

### 💻 User Experience
- **Responsive Design**: Optimized for all screen sizes (mobile, tablet, desktop)
- **Interactive Surveys**: Dynamic question progression with progress tracking
- **Smart Navigation**: Previous/Next functionality with answer validation
- **Tooltip System**: Explanatory popups for better user understanding

### 📊 Data Management
- **CRUD Operations**: Browse, filter, and view detailed laptop specifications
- **Category Filtering**: Filter laptops by use case
  - 💻 Programming
  - 🎮 Gaming
  - 🎨 Design
  - 🎬 Video Editing
- **Detailed Views**: Comprehensive laptop specifications
